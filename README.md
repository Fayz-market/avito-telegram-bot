# Telegram Bot для мониторинга Авито 🤖

Бот помогает пользователям быстро находить новые объявления на Авито. Он отслеживает новые публикации по заданным категориям и отправляет уведомления в Telegram.

## Функции

- 📌 **Подписка на категории товаров** - выбери интересующие тебя категории
- 🔔 **Уведомления в Telegram** - получай оповещения о новых объявлениях
- 🔍 **Фильтрация по ключевым словам** - уточни поиск по своим критериям
- 💰 **Фильтр по цене** - установи минимальную и максимальную цену
- ⚙️ **Управление подписками** - легко добавляй и удаляй категории

## Поддерживаемые категории

- 📱 Смартфоны
- 🍎 iPhone
- 🤖 Android
- 🎮 Игровые приставки
- 💻 Ноутбуки
